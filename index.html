¿Cómo descargar?

📱 Desde el celular

  1. Toca el botón Descargar del archivo que necesitas.
  2. Si el navegador pregunta, confirma con Descargar o Permitir.
  3. Busca el archivo en la carpeta Descargas (Android) o en la app Archivos (iPhone).
  4. Para el currículum (.docx), ábrelo con Word o Google Docs para editarlo.

💻 Desde el computador

  1. Haz clic en Descargar.
  2. El archivo quedará en tu carpeta Descargas.
  3. Haz doble clic para abrirlo.

⚠️ Si no se descarga

  • Mantén presionado el botón y elige "Descargar enlace" (celular), o clic derecho → "Guardar enlace como…" (computador).
  • Revisa tu conexión a internet y el espacio disponible en tu dispositivo.
  • Si el PDF se abre en el navegador en vez de descargarse, usa el ícono de descarga ⬇️ que aparece arriba o abajo del visor.
